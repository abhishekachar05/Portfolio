## ✨ Features

- 🌌 **Animated particle background** — Three.js powered WebGL canvas animation
- 🎨 **Dark mode design** — Premium dark aesthetic with gradient accents
- ⌨️ **Command palette** — `Ctrl/Cmd + K` to quickly navigate sections
- 🖱️ **Custom cursor** — Smooth animated cursor with hover effects
- 📜 **Smooth scrolling** — Powered by Lenis scroll library
- 🌍 **Multi-language support** — Built-in translation system
- 📱 **Fully responsive** — Mobile, tablet, and desktop ready
- 🎞️ **Scroll reveal animations** — Elements animate as you scroll
- 📄 **Resume viewer** — Direct PDF resume access

## 🚀 Running Locally

No build step needed — it's plain HTML/CSS/JS.

1. Clone the repo:
   ```bash
   git clone https://github.com/abhishekachar05/Portfolio.git
   ```
2. Open `index.html` in your browser, or use a live server:
   ```bash
   # With VS Code Live Server extension, right-click index.html → Open with Live Server
   ```
